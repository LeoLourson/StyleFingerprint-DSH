Квазиклассическое приближение для несамосопряженной задачи Штурма–Лиувилля с параболическим потенциалом В. И. Покотило, А. А. Шкаликов

1. Постановка задачи. В работе изучается несамосапряженная задача Штурма–Лиувилля вида iεy′′ + q(x)y = λy, y (a) = y(b) = 0, (1.1) которая ассоциируется с известным в гидродинамике оператором Орра–Зоммерфельда.

Здесь λ – спектральный параметр, ε – малый параметр, который пропорционален вязкости жидкости и обратно пропорционален числу Рейнольдса,q(x) – скорость стационарного профиля жидкости в каналеa 6 x 6 b. Исследуется поведение спектра соответствующего семейства дифференциальных операторов L(ε)y = iεy′′ + q(x)y, ε > 0, (1.2) действующих на отрезке[a, b], с краевыми условиями y(a) = y(b) = 0 (1.3) при ε → 0 с аналитическими функциями q(x), имеющими один экстремум на отрезке [a, b]. Найден предельный спектральный граф рассматриваемой модельной задачи –предельные кривые, вдоль которых происходит концентрация спектра.

В литературе наиболее часто встречаются два стационарных профиля скорости, именно, q(x) = x и q(x) = x2. Первый называетсяпрофилем Куэтта, второй –профилем Пуазейля. Случай профиля Куэтта изучен в работе [1], где предельное множество, вдоль которогоконцентрируютсясобственныезначения, названоспектральнымгалстуком. Эта задача получила свое обобщение в работе Шкаликова [2], где был рассмотрен случай монотонного на отрезке профиля течения и доказано, что предельное множество состоит из трех кривых, также по форме напоминающих галстук. В работе [2] также приведены результаты для случая профиля Пуазейля, который подробно изучен в [3] для симметричного квадратичного потенциала и в [4] для несимметричного квадратичного потенциала. В указанных работах предельное множество, около которого концентрируются собственные значения, названо предельным спектральным графом. В нашей работе, которая направлена на обобщение результатов [4], мы также будем придерживаться этой терминологии.

Мы покажем, что спектральный портрет в случае несимметричного квадратичного потенциала, найденный в [4], не случаен; похожая картина наблюдается для широкого класса аналитических функций q(x), обладающих одним экстремумом на заданном отрезке.

В упомянутых работах отмечено, что в случае аналитической функцииq(x) спектр концентрируетсявблизинекоторыхкривых, формакоторыхопределяетсягеометриейлиний Стокса уравнения (1.1). Для понимания основных утверждений, доказанных в данной работе, читателю следует ознакомиться с основными определениями теории графов Стокса, подробное изложение которой можно найти, например, в [5].

Для простоты можно считать, что q(x) продолжается во всю комплексную плоскость как целая функция, но можно ограничиться только требованием ее аналитичности в окрестности отрезка [a, b] вдобавок к основным условиям, которые сформулированы ниже. Не ограничивая общности, мы можем рассматривать случайa < 0 < b, 0 = q(0) < q(a) < q(b), полагая, что функцияq(x) убывает на отрезке[a, 0] и возрастает на отрезке[0, b]. Тогда область значений функцииq(x) при x∈ [a, b] есть отрезок[0, q(b)].

В этом случае область значений квадратичной формы изучаемого семейства операторов (Ly, y) лежит в полуполосе Π ={λ∈ C| Im λ <0, 0 < Re λ < q(b)}.

Так как спектр оператора заключен в его числовом образе, то при любомε >0 собственные значения задачи лежат в этой полуполосе.

Теперь сформулируем основные условия на функциюq(x).

Условие (i). Функция q(x) вещественна при x∈ [a, b], убывает на отрезке [a, 0] и возрастает на отрезке[0, b], причем a <0 < b, 0 = q(0) < q(a) < q(b). Существуют не пересекающиеся областиG1, G2⊂ C,имеющие в качестве части своей границы отрезки [a, 0] и [0, b] соответственно, такие, что q(z) аналитична в G1, G2 и биективно отображает G1 на полуполосу Π1, а G2 на полуполосу Π (здесь черта означает замыкание областей), где Π1 ={λ∈ C| Im λ <0, 0 < Re λ < q(a)}.

Условие (ii). При любом c∈ (0, q(a)) прообраз луча rc ={λ| λ = c− it, 0 6 t <∞} в G1 есть функция относительно мнимой оси, т.е. любая прямая Im λ = const пересекает прообраз луча rc только один раз, либо не пересекает вовсе. Аналогично, при любом c∈ (0, q(b)) прообраз луча rc в G2 есть функция относительно мнимой оси.

Из этих условий по принципу соответствия границ следует, что областьG1 полностью лежит в верхней полуплоскости, а областьG2 полностью лежит в нижней. Примерами функций, удовлетворяющих сформулированным двум условиям, могут служитьq(x) = x2 на отрезке [−1, 2], q(x) = 1− cos(x) на отрезке [−π/2, π] и другие.

Доказательство. Далее используем результаты асимптотической теории для обыкновенных дифференциальных уравнений, с которыми можно познакомиться в [5].

Важную роль в этой теории играют функции S1(z, λ) = Z z ξ1 λ p i(q(ξ)− λ) dξ, S 2(z, λ) = Z z ξ2 λ p i(q(ξ)− λ) dξ, которые мы определяем при λ∈ Π1 и λ∈ Π соответственно. Здесь мы опускаем ряд технических деталей, связанных с голоморфностью и аналитичностью, необходимых для дальнейшего корректного использования этих функций. При фиксированном λ∈ Π1, λ∈ Π множество {z| Re S1,2(z, λ) = 0} определяет кривые вz-плоскости, которые называютсялиниями Стокса. Точки ξ1 λ и ξ2 λ принадлежат этому множеству и из них выходит по три линии, образуя два комплекса Стокса. Граф Стокса, образованный этими комплексами, может быть сложным – тогда он содержит конечную линию Стокса, соединяющую точкиξ1 λ и ξ2 λ. В случае простого графа Стокса – две линии каждого комплекса асимптотически стремятся к линиям второго комплекса. Условно будем называть ихвнутренними, а третью линию каждого комплекса –внешней. Введем для них следующие обозначения:l1 1,2 (соответственно l2 1,2) – внутренние линии комплекса Стокса с центром вξ1 λ (соответственно ξ2 λ), а l1 3 и l2 3 –внешние, причем l1 1 асимптотически стремится кl2 2, а l2 1 к l1 2.

Пусть λ = c− it. Из условий (i), (ii) мы имеем, чтоξ1 λ∈ G1 лежит в верхней полуплоскости, ξ2 λ∈ G2 лежит в нижней полуплоскости. При этом выполнена следующая цепочка неравенств: a < ξ1 c < 0 < ξ2 c < b.

Принципиальную роль для дальнейшего играет следующее утверждение.

Лемма 2.4. Пусть λ∈ Π\ (γ0∪ γ1 a∪ γ2 a∪ γ2 b). Рассмотрим следующие случаи:

1) точка λ лежит выше кривыхγ0 и eγ 1 a; 2) λ лежит ниже кривойγ0, но выше кривойeγ 1 a; 3) λ∈ eγ 1 a\ γ1 a, т.е. лежит на eγ 1 a, но находится ниже кривойγ0; 4) λ лежит ниже кривойeγ 1 a, правее кривой γ2 a и выше кривойeγ 2 b; 5) λ лежит ниже кривойeγ 1 a, левее кривой γ2 a и выше кривойeγ 2 b; 6) λ∈ eγ 2 b\ γ2 b, т.е. лежит на eγ 2 b, но находится левее кривойγ2 a; 7) λ лежит ниже кривойeγ 2 b.

Тогда пересечение графом Стокса отрезка[a, b] исчерпывается следующим.

1. Линия l1 3 проходит через интервал (a, ξ1 c), а l2 3 – через (ξ2 c, b). Линии l1 2 и l2 2 пересекают интервал (ξ1 c, ξ2 c) в точках x1(λ) и x2(λ) соответственно, причем x1 < x2.

2. Линия l1 1 проходит через интервал (a, ξ1 c), а l2 1 – через (ξ2 c, b). Линии l1 2 и l2 2 пересекают интервал (ξ1 c, ξ2 c) дважды либо не пересекают вовсе.

3. Линия l1 1 проходит через точку a, а l2 1 – через интервал (ξ2 c, b). Линии l1 2 и l2 2 пересекают интервал (ξ1 c, ξ2 c) дважды либо не пересекают вовсе.

4. Одна линия Стокса, выходящая из точки ξ2 λ, проходит через интервал (ξ2 c, b).

Внутренние линии каждого из комплексов, асимптотически не стремящиеся друг к другу, пересекают интервал (a, ξ2 c) один раз либо два, либо сливаются, либо не пересекают вовсе.

5. Линия l2 1 проходит через интервал (ξ2 c, b), а линия l2 2 – через (a, ξ1 c). Линия l1 2 пересекает интервал (ξ1 c, ξ2 c) дважды либо не пересекают вовсе.

6. Линия l2 1 проходит через точку b, а линия l2 2 – через (a, ξ1 c). Линия l1 2 пересекает интервал (ξ1 c, ξ2 c) дважды либо не пересекают вовсе.

7. Линии l1 1 и l2 1 не пересекают отрезок[a, b]. При этом линииl2 2 и l1 2, асимптотически стремящиеся к первым двум, могут пересекать отрезок[a, b] каким-либо образом.
